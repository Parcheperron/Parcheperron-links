# Parche Perrón — página de enlaces

## Cambiar enlaces
1. En GitHub abre `config.js`.
2. Pulsa el lápiz (Edit).
3. Cambia el valor `null` por un enlace entre comillas, por ejemplo `"https://www.instagram.com/tu_cuenta/"`.
4. Para WhatsApp, escribe el número con indicativo 57 entre comillas (ejemplo ficticio: `"573001234567"`).
5. Pulsa **Commit changes**. GitHub Pages publicará los cambios automáticamente tras unos minutos.

## Publicar
1. Crea un repositorio **público** `parcheperron-links` en GitHub.
2. Sube **el contenido de esta carpeta a la raíz del repositorio**: `index.html`, `config.js`, `README.md` y la carpeta `assets`.
3. Ve a Settings > Pages > Build and deployment, selecciona **Deploy from a branch**, rama **main** y carpeta **/(root)**, y guarda.
4. El sitio estará en `https://TU_USUARIO.github.io/parcheperron-links/`.

## Logo y fuente
El logotipo original está en `assets/logo-parcheperron.png`. La tipografía BIGAIL PERSONAL USED no se incluye: verifica su licencia comercial antes de usarla en la web.

**Nota:** Los enlaces están pendientes de completar. No introduzcas contraseñas ni datos privados: el repositorio es público.
